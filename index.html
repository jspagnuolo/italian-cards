    Move progress to another device

    Progress is saved on each device separately. To carry it over: on the old device tap Copy progress (or Save progress file), then on the new device paste it below (or choose the file) and tap Import. Imports merge; nothing is lost.

    Install on your phone, tablet or computer
    • iPhone / iPad: open this page in Safari, tap Share, then Add to Home Screen. Open it from the home-screen icon from then on.
    • Android: in Chrome, tap the ⋮ menu, then Install app (or Add to Home screen).
    • Mac: in Safari, File → Add to Dock. In Chrome, click the install icon at the right of the address bar.
    • Linux: in Chrome or Chromium, use the install icon in the address bar. In Firefox, just bookmark it; it still works offline after the first visit.
    • Open it once while online after each class so the new cards download. After that, no connection needed.
